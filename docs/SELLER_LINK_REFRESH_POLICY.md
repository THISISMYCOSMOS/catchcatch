# 판매처 링크 재조회 및 가격 이력 정책

## 핵심 원칙

- `seller_offers.seller_url`에는 검증된 원본 상품 URL을 보관한다.
- 저장된 가격을 현재가로 재사용하지 않는다. 다음 분석에서는 저장 URL을 먼저 다시 열어 현재 가격과 구매 가능 여부를 확인한다.
- 직접 검증에 성공한 판매처는 유료 웹 검색 대상에서 제외한다.
- URL 접근 실패, 품절, 상품·옵션 불일치 또는 직접 추출 미지원인 판매처만 웹 검색으로 보완한다.
- 이번 검색에서 검증되지 않은 오퍼는 `is_active=false`로 내려 계산에서는 제외하되, URL은 다음 재탐색 힌트로 남긴다.
- 새 분석에서 확인된 가격은 분석 저장 트랜잭션을 통해 `price_history`에 관측값으로 추가한다. 이전 가격은 외부에서 소급 조회하는 값이 아니라 CatchCatch가 과거에 직접 저장한 관측값이다.

## 판매처별 적용 방식

| 판매처 | 저장 URL 재사용 | 현재가 확인 | 실패 시 처리 |
| --- | --- | --- | --- |
| 무신사 뷰티 | 가능 | 상품 페이지 직접 검증 | 웹 검색 보완 |
| 지그재그 | 가능 | 공개 상품 데이터 직접 검증 | 웹 검색 보완 |
| 쿠팡 | 가능 | 저장 URL을 우선 힌트로 사용하고 파트너스 상품 API 확장 가능 | 웹 검색 보완 |
| 올리브영 | 가능 | 저장 URL을 우선 힌트로 사용 | 접근 제한 또는 추출 실패 시 웹 검색 보완 |
| 브랜드 공식몰 | 가능 | 등록·검증된 공식 도메인 안에서 URL 우선 확인 | 몰별 구조가 달라 웹 검색 보완 |

따라서 이 구조는 쿠팡 전용이 아니다. 공통 저장·활성 상태·가격 이력 계층 위에 판매처별 현재가 어댑터를 붙이는 방식이며, 새 쇼핑몰은 직접 검증 어댑터와 허용 도메인을 추가하면 된다.

## 쿠팡 파트너스

- 원본 `seller_url`은 증거 URL로 계속 보존한다.
- 파트너스 딥링크 변환 성공 시에만 `purchase_url`에 저장하고 화면의 구매 링크로 사용한다.
- 변환 실패나 기능 비활성 상태에서는 원본 URL로 안전하게 폴백한다.
- API 키는 백엔드 환경변수에만 저장한다.
- 파트너스 링크가 실제 사용된 결과 화면에는 쿠팡이 지정한 경제적 이해관계 문구를 표시한다.

환경변수:

```dotenv
COUPANG_PARTNERS_ENABLED=true
COUPANG_PARTNERS_ACCESS_KEY=
COUPANG_PARTNERS_SECRET_KEY=
COUPANG_PARTNERS_API_BASE_URL=https://api-gateway.coupang.com
COUPANG_PARTNERS_TIMEOUT_MS=3000
```

쿠팡의 일반 Seller Open API는 판매자가 등록한 자기 상품 운영용이며 전체 마켓 가격 검색 API와는 용도가 다르다. 전체 상품 검색과 딥링크는 [쿠팡 파트너스 가이드](https://partners.coupangcdn.com/partners-guide/partners-guide-20250714121952.pdf)의 파트너스 API 범위다. Seller API의 상품 조회 범위는 [쿠팡 공식 상품 조회 문서](https://developers.coupangcorp.com/hc/ko/articles/360033644994-%EC%83%81%ED%92%88-%EC%A1%B0%ED%9A%8C)에서 확인할 수 있다.

## 운영상 다음 개선 순서

1. 판매처별 `last_refresh_status`, 실패 사유, 연속 실패 횟수를 저장해 깨진 링크 교체 시점을 정한다.
2. URL 정규화와 판매처 상품 ID를 함께 저장해 추적 파라미터 변화로 중복 오퍼가 생기는 것을 줄인다.
3. 판매처별 최소 재조회 간격과 지수 백오프를 적용해 차단 및 API 호출량을 줄인다.
4. 파트너스 상품 API 승인이 완료되면 쿠팡 현재가 어댑터를 추가하고, 딥링크 변환은 새 URL 발견 시에만 수행한다.
